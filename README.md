# romina.work

Single page for [romina.work](https://romina.work): a drawing, and the line “in construction.”

Static HTML and CSS at the repository root, for GitHub Pages from the `main` branch (Deploy from a branch, folder `/`). `.nojekyll` keeps Pages from running Jekyll. The domain is set in `CNAME`.

The caption is set in [Newsreader](https://github.com/productiontype/Newsreader), licensed under the SIL Open Font License (`fonts/OFL.txt`).
